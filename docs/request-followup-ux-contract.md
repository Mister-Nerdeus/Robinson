# Request Follow-Up UX Contract

## Goal
Users should understand what happens after form submission across intake lanes.

## Rules
- Emergency flows remain call-first.
- Contact and service pages include concise "What happens next" guidance.
- Response expectation copy must be realistic and non-promissory.
- Added blocks must remain mobile-readable and lightweight.

## Scope
- `/contact`
- `/services/septic-cleaning`
- `/services/well-septic-evaluations`
- `/services/portable-toilets`
- `/services/commercial`
- `/realtors`
