# Homepage Section Job Map

| Section | Primary Job |
| --- | --- |
| Hero | Establish urgency and expose one call-first path plus one request path. |
| Service chooser | Help visitors self-sort into the right service route. |
| Trust band | Prove longevity and service scope with verified facts only. |
| Realtor band | Protect the home-sale evaluation lane as a distinct premium route. |
| FAQ preview | Answer a few pre-service questions without retelling the homepage. |
| Final CTA | Offer a last clear action without adding new proof copy. |
