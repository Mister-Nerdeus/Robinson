# Dispatch SOP General

## Goal
Handle general contact requests with fast callback and accurate lane routing.

## Steps
1. Open admin submissions workspace and filter `type=general`.
2. Confirm caller contact details and preferred callback timing.
3. Route to septic/evaluation/rental/commercial lane if request is mis-laned.
4. Set lifecycle from `new` -> `contacted` with internal note.
5. Escalate unresolved routing or missing data to owner.
