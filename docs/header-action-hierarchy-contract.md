# Header Action Hierarchy Contract

## Goal
Keep the sticky header clear, lighter in visual chrome, and subordinate to hero messaging.

## Desktop Hierarchy
1. Brand identity.
2. Primary nav links.
3. Primary CTA: call.
4. Secondary CTA: request service.

## Mobile Hierarchy
1. Brand + emergency context.
2. Menu toggle.
3. Sticky mobile action rail for call/request actions.

## Rules
- Emergency phone access remains immediate.
- Sticky behavior remains enabled.
- Navigation remains available on desktop and mobile.
- Mobile layout must remain unclipped at 360, 390, and 430 widths.
- Mobile action rail must reinforce, not conflict with, header CTA priority.

## Top Emergency Bar Decision
- Kept, but reduced to a quieter slim strip with direct call text.
