# Homepage Message Compression Contract

## Purpose
Keep the homepage intent-driven instead of re-explaining the same business story in every section.

## Rules
- Each homepage section gets one job only.
- Trust proof stays in the trust band.
- Home-sale proof stays in the Realtor band.
- The homepage does not narrate internal workflow.
- Repeated phrases are capped explicitly.

## Banned Workflow Terms
- `workflow`
- `router`
- `triage`
- `intake`
- `task lane`
- `secondary route links`

## Repetition Caps
| Phrase | Maximum Allowed Occurrences |
| --- | --- |
| `family owned and operated since 1979` | 1 |
| `choose your service` | 1 |
| `request service` | 4 |

## Executable Gate
- `npm run test:homepage-message-compression-contract`
