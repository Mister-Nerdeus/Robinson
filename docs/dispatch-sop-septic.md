# Dispatch SOP Septic

## Goal
Prioritize emergency septic requests and dispatch efficiently.

## Steps
1. Filter `type=septic-service`.
2. Review urgency, tank count, lids exposed, and access issues.
3. For emergency requests, call-first workflow and immediate dispatch triage.
4. Update lifecycle (`new` -> `in-progress` -> `scheduled`) with notes.
5. If delivery/notification failed, use incident playbook forms.
