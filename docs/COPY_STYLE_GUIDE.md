# COPY_STYLE_GUIDE

## Voice
- Task-first, lane-specific, operationally clear.
- Emergency copy should be direct and call-first.
- Routine copy should state follow-up and scheduling expectations.

## CTA Rules
- Use task language (`Request Grease Trap Service`, `Start Rental Quote`).
- Avoid generic CTA labels (`Learn More`, `Click Here`, `Contact Us For Anything`).

## Banned Phrase List
- contact us for anything
- learn more
- click here
- best-in-class
- world class
